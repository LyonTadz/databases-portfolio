§14  Task 2 — the alarm hole: a correction that never alarms
==============================================================================

  fix A        stored value 3.4 (> 2.0 threshold), alarms = 0
  -> neither fix closes it: the alarm trigger is AFTER INSERT and this took DO UPDATE.

    ingest value 3.4: alarms = 1
    ingest value 3.4: alarms = 1

    [(3.4, 'vibration over 2.0 mm/s (on correction)')]
  -> OLD.value <= 2.0 makes it edge-triggered: it fires on the crossing, not on every replay above the line.
